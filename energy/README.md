# 🔋 Energy Optimizer

하루의 **시간**을 **에너지(HP·MP)** 로 환산해서, 한정된 자원을 어디에 쓸지 정하는 앱.
"오늘 내가 몇 점인가"가 아니라 **"이걸 감당할 수 있나 / 지금 뭘 하는 게 맞나"** 에 답하는 것이 목표다.

- **HP** — 몸의 자원 (근육 피로·심폐 부담·신체적 피곤)
- **MP** — 머리의 자원 (집중력·인지/의사결정/사회적 피로)
- **예산(Budget)** — 지금부터 취침까지, 안전 예비분을 남기고 쓸 수 있는 양

## 핵심 루프

```
활동 선택 → 예상 부하 → 실제 수행 → 2문항 피드백 → 개인계수 학습 → 다음 예측이 정확해짐
```

사용자는 활동이 끝나고 **"앱 예상보다 어땠는지"** 만 답한다(😌 😐 😓 🥵).
예측에는 이미 개인계수가 반영돼 있으므로, 그 비율을 EMA로 곱해 나가면 계수가 자연히 수렴한다.
20번쯤 쌓이면 "당신에게 테니스는 기본보다 몸 부하가 약 40% 높습니다" 같은 문장이 나온다.

## 모델

```
Load = 활동 기본치(시간당) × 시간 × 강도 × 지속시간 패널티 × 개인계수 × 컨텍스트
```

- **컨텍스트**: 수면 부족, 현재 고갈 정도(지칠수록 같은 일이 더 비싸다), 회복부채, 컨디션 태그
- **회복**: 깨어 있는 동안의 자연 회복(점근적) + 수면 회복 + 회복부채(고강도 활동의 잔여 비용)가 회복 속도를 늦춤
- **시뮬레이션**: 계획을 시간순으로 훑으며 매 단계 상태를 갱신 → 하루의 **최저점**과 **취침 시점**을 예측
- **제안**: 각 일정을 30분 줄였을 때 최저점이 얼마나 올라가는지 계산해 가장 효과 큰 것을 제시

엔진은 `src/engine/`에 순수 함수로 분리돼 있다.

| 파일 | 역할 |
|---|---|
| `model.js` | 부하·회복·컨텍스트·하루 시뮬레이션·판정·조정 제안 |
| `learn.js` | 피드백 → 개인계수 학습, 활동별 통계, 하루 기록 정리 |
| `patterns.js` | 하루 기록에서 개인 패턴 추출 (수면·취침 시각·낮잠·요일). **표본이 충분한 것만** 문장으로 만든다 |
| `rules.js` | 오늘 상황에 패턴과 운영 원칙을 대입해 경고를 만든다 |
| `recommend.js` | "지금 뭐 하지?" 추천 |
| `importer.js` | 느슨한 형식의 외부 데이터 가져오기 |
| `activities.js` | 기본 활동 35종 |

## 개인화 규칙 (rules.js)

활동을 이름으로 분류하지 않고 **활동 자체의 성격**으로 판단한다 — 사회 부하 `soc ≥ 6`이면 "사람 쓰는 일",
회복 비용 `rec ≥ 0.7`이면 "여파가 남는 운동". 그래서 새 활동을 만들어도 규칙이 그대로 적용된다.

- 어젯밤 취침이 01:30 이후 → 그 사람의 실제 밴드 통계를 근거로 경고
- 2시간 이상 낮잠 → 그날 밤 취침 지연 경고
- 사람 쓰는 일 2건 이상 겹침 → 하나를 옮기라고 제안
- 최근 7일 고강도 운동 3회 이상 → 주 2회 상한 초과
- 계획이 예산의 75% 초과 → 70~75% 원칙 위반 / 이하면 "Mission Complete" 확인
- 지금 MP < HP−10 → 머리 쓰는 일부터 덜어내라고 안내
- 계획이 비어 있음 → 빈 날이 오히려 무너지기 쉬웠다는 경고

## 개발

```bash
cd energy/app
npm install
npm run dev      # http://localhost:5178
npm run build    # → ../../docs/energy (GitHub Pages 배포용)
```

아이콘을 바꾸려면 `energy/tools/make_icons.py`를 수정하고 실행 (외부 라이브러리 불필요).

## 데이터

모든 기록은 **브라우저 localStorage** 에만 저장된다. 서버도 계정도 없다.
기기를 옮길 때는 설정 → 내보내기(JSON) → 새 기기에서 가져오기.
다른 곳에 있던 기록을 옮겨올 때는 [IMPORT.md](IMPORT.md) 참고 — 느슨한 형식도 받아서
예상 부하·개인계수를 엔진으로 다시 계산해 준다.

## 핸드폰에 설치

배포된 주소를 열고 —
- iPhone: Safari 공유 → "홈 화면에 추가"
- Android: Chrome 메뉴 → "앱 설치"

설치하면 주소창 없이 앱처럼 뜨고, 오프라인에서도 동작한다(서비스워커가 앱 셸을 캐시).
